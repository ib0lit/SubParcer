## 📖 О проекте

**SubParser** — многопоточный инструмент автоматизации для OpenWrt: загрузка подписок (VLESS Reality/TLS, Trojan, Hysteria2), скрининг и стресс-тестирование узлов через изолированный инстанс `sing-box`, дедупликация и бесшовная выгрузка лучших прокси в секции пакета **Podkop**.

---

## ✨ Ключевые возможности

### 🚀 Высокопроизводительный отбор узлов

* **Многопоточный тест (до 12 потоков одновременно)**: проверка пула серверов занимает считанные секунды.


* **Двухэтапная фильтрация**:


1. *Быстрый скрининг*: мгновенная проверка отклика каждого узла через генерацию HTTP 204-запросов.


2. *Анализ стабильности (Stability Test)*: серия из 5 последовательных замеров для вычисления медианы задержки и отсева джиттера (узлов с нестабильным пингом и потерями).




* **Поддержка протоколов**: VLESS (Reality, TLS, WebSocket, gRPC, XHTTP), Trojan, Hysteria2.


* **Интеллектуальный фильтр RU**: автоматическое исключение российских узлов и серверов обхода белых списков внутри РФ. (отключается в настройках)


* **Лимитирование пула (Top-N)**: возможность экспортировать только Топ-3, Топ-5, Топ-10 быстрейших узлов или оставить все прошедшие отбор.



---

### 📁 Гибкая интеграция с Podkop

* **Мультисекционность**: прозрачная работа с любыми стандартными (`main`) и пользовательскими секциями Podkop.


* **Два режима записи**:


* *Замена (Replace)*: полная перезапись списка серверов отобранными быстрыми узлами.


* *Добавление (Append)*: объединение с имеющимися серверами с умной дедупликацией по цифровому отпечатку (fingerprint).




* **Индивидуальная настройка**: возможность задавать персональный режим работы и лимиты для каждого профиля отдельно.



---

### 🤖 Полнофункциональный Telegram-бот

Бот разворачивается как отдельный легковесный `procd`-демон и управляется модульной архитектурой (`/usr/lib/subparser/`):

* **Менеджер подписок**: добавление провайдеров отправкой ссылки в чат, автоопределение типа подписки, переключение User-Agent (`v2rayN`, `FlClash`, `Sing-Box`, `Happ`, `Incy`), включение/выключение и удаление источников.


* **Управление серверами**: просмотр карточек узлов с реальным пингом, ручное переключение на любой из серверов в списке или сброс в авторежим (`URL-Test`), точечное удаление нерабочих нод.


* **Контроль клиентов сети**: просмотр подключённых Wi-Fi (2.4/5 GHz, уровень сигнала в dBm) и LAN-клиентов. Мгновенная блокировка и разблокировка доступа в интернет для выбранного MAC-адреса через `nftables`.


* **Диагностика сервисов**: параллельный тест доступности YouTube, Discord, Steam, Instagram, TikTok и сервисов РФ с определением типа маршрута (туннель Podkop Fake-IP или прямой провайдер).


* **Системный монитор**: отображение температуры процессора (SoC), аптайма, использования RAM, просмотр логов (`logread`, `dmesg`, лог парсера) и удалённый перезапуск роутера или службы Podkop.



---

### 🌐 Веб-интерфейс LuCI

Интуитивная панель управления, встроенная в веб-интерфейс роутера (**Службы → SubParser**):

* **Вкладка «Основные настройки»**: включение службы, порог отсева пинга, лимит серверов, фильтрация RU, кнопка ручного запуска с логом в реальном времени.


* **Вкладка «Секции Podkop»**: выбор профилей и режимов обновления.


* **Вкладка «Telegram»**: настройка токена, Chat ID и проверка отправки тестового уведомления.


* **Вкладка «Подписки»**: таблица источников с выбором User-Agent.


* **Интерактивный дашборд**: плиточный список серверов внизу страницы с измерением задержки и ручным сохранением выбранных чекбоксами узлов.



---

### ⏱ Автономность и Watchdog

* **Гибкий планировщик**: запуск раз в 1ч, 12ч, 24ч, каждые N часов или ежедневно в точное время (`ЧЧ:ММ`).


* **Сторожевой таймер (`subparser-watchdog.sh`)**: каждые 5 минут проверяет отклик REST API ядра `sing-box`. При зависании службы или падении прокси автоматически перезапускает службу и запускает экстренный перепарсинг узлов с уведомлением в Telegram.

## 🛠 Установка

Подключитесь к маршрутизатору по SSH и выполните команду:

```sh
sh -c "$(curl -sL https://raw.githubusercontent.com/ib0lit/SubParser/main/install.sh)"

```

Скрипт автоматически:

1. Определит тип пакетного менеджера (`apk` для OpenWrt 25+ или `opkg` для OpenWrt 19–24).


2. Доустановит системные зависимости: `python3`, `curl`, `conntrack-tools`, `ca-certificates`.


3. Развернёт модульную структуру файлов, настроит права доступа и выполнит предкомпиляцию байткода Python.


4. Зарегистрирует службы в `procd`, задачи в планировщике `cron` и обновит кэш LuCI.



После установки перейдите в веб-интерфейс: **LuCI → «Службы» → «SubParser»**.

---

## 🔄 Обновление

Для перехода на новую версию без потери подписок, настроек и токенов бота:

```sh
sh -c "$(curl -sL https://raw.githubusercontent.com/ib0lit/SubParser/main/update.sh)"

```

Инсталлятор сравнивает локальный SHA коммита с веткой `main` на GitHub, загружает актуальный релиз, безопасно мигрирует структуру и выполняет мягкое обновление UCI-конфигурации.

---

## 🗑 Удаление

Полная очистка маршрутизатора от сервиса, расписания и временных файлов:

```sh
sh -c "$(curl -sL https://raw.githubusercontent.com/ib0lit/SubParser/main/uninstall.sh)"

```

## 🧩 Совместимость

### Операционные системы (OpenWrt)

| Версия OpenWrt | Пакетный менеджер | Подсистема Firewall | Статус поддержки |
| --- | --- | --- | --- |
| **OpenWrt 25.x** | `apk` | fw4 (`nftables`) | Полная совместимость ✅ |
| **OpenWrt 24.10** | `opkg` | fw4 (`nftables`) | Полная совместимость ✅ |
| **OpenWrt 23.05** | `opkg` | fw4 (`nftables`) | Полная совместимость ✅ |
| **OpenWrt 22.03** | `opkg` | fw4 (`nftables`) | Полная совместимость ✅ |
| **OpenWrt 21.02** | `opkg` | fw3 (`iptables`) | Базовый функционал (без блокировки клиентов) ⚠️ |

> **Примечание по OpenWrt 21.02**: парсинг, веб-интерфейс LuCI и управление узлами работают штатно. Функция быстрой аппаратной блокировки клиентов по MAC через Telegram-бот опирается на таблицы `nftables` (`fw4`) и не поддерживается на устаревшем `iptables`.
> 
> 

### Пакет Podkop

SubParser взаимодействует с **Podkop** через стандартную подсистему UCI (`/etc/config/podkop`):

* **Совместимость с версиями**: поддержка всех актуальных версий Podkop и его форков.
* **Секции маршрутизации**: автоопределение базовых (`main`) и любых кастомных пользовательских секций (`test`, `custom`, `sec2`).


* **Формат данных**: чтение и запись стандартных списков `urltest_proxy_links` и параметров выбора активного сервера.



### Ядро `sing-box`

* **Версии ядра**: рекомендуется `sing-box` версии **1.8.0** и выше.
* **Стресс-тестирование**: скрипт генерирует чистые временные JSON-конфигурации и поднимает изолированный инстанс на свободном порту без вмешательства в рабочий трафик.


* **Поддерживаемые протоколы**:
* **VLESS**: Reality, TLS, WebSocket, gRPC, XHTTP.


* **Trojan**: TLS, gRPC, WebSocket.


* **Hysteria2**: нативная поддержка с проверкой задержки и джиттера.




* **REST API**: мониторинг и замеры задержки в боте осуществляются через стандартизированный Clash API ядра (порт `9090`).
