# **SubParser для OpenWrt**

Сервис автоматической загрузки, фильтрации и мониторинга подписок на узлы прокси/VPN для маршрутизаторов под управлением OpenWrt. Решение интегрируется в стандартный веб\-интерфейс LuCI и включает Telegram-бота для удаленного контроля и получения уведомлений.

## **Основные возможности**

* **Универсальная поддержка версий**: полная совместимость с современными версиями OpenWrt на базе менеджера apk (ветка 24+ / 25+) и классическими релизами на базе opkg (ветки 21–23).  
* **Фильтрация и замер задержки**: автоматическое исключение узлов RU-зоны, расчет времени отклика (RTT/ping) и отсев нестабильных серверов по порогу джиттера.  
* **Управление через LuCI**: графический интерфейс для настройки расписания, указания пороговых значений задержки, ввода ссылок подписок и ручной синхронизации.  
* **Фоновый демон и Watchdog**: автоматический контроль работоспособности процессов через системный планировщик cron.  
* **Telegram-бот**: проверка статуса сервиса, ручной запуск обновления и получение оповещений о состоянии узлов.

## **Требования к системе**

* OpenWrt 21.02 / 22.03 / 23.05 (opkg) или OpenWrt 24.10 / 25.x (apk).  
* Доступ к маршрутизатору по протоколу SSH с правами суперпользователя root.  
* Установленный пакет curl для запуска скрипта загрузки.

## **Установка**

Подключитесь к маршрутизатору по SSH и выполните команду первичной установки:

```bash
sh -c "$(curl -sSL -H 'Cache-Control: no-cache' https://raw.githubusercontent.com/ib0lit/SubParcer/main/install.sh)"
```

Команда автоматически:

1. Определит пакетный менеджер системы (apk или opkg) и установит недостающие пакеты (python3, curl, conntrack).  
2. Развернет исполняемые скрипты, службу LuCI и модули ACL.  
3. Сохранит текущую ревизию коммита в /etc/subparser\_version.  
4. Запустит фоновые демоны и обновит кэш интерфейса LuCI.

## **Обновление**

Для обновления сервиса на маршрутизаторе выполните:

```bash
sh -c "$(curl -sSL -H 'Cache-Control: no-cache' https://raw.githubusercontent.com/ib0lit/SubParcer/main/update.sh)"
```

Скрипт проверяет SHA последнего коммита через GitHub API. Если на маршрутизаторе уже установлена актуальная версия, скрипт завершит работу без перезаписи файлов и перезапуска демонов.

## **Первоначальная настройка**

1. Перейдите в веб\-интерфейс маршрутизатора по адресу http\://192.168.1.1.  
2. Откройте раздел **«Службы»** → **SubParser**.  
3. На вкладке настроек укажите:  
   * **Ссылки на подписки**: список рабочих URL.  
   * **Порог пинга / Jitter**: параметры отбора серверов.  
   * **Telegram Bot Token / Chat ID** (опционально): данные созданного бота для управления через мессенджер.  
4. Нажмите **Сохранить и применить**.
