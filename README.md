**SubParser** — многопоточный инструмент автоматизации для OpenWrt: загрузка подписок (VLESS Reality/TLS, Trojan, Hysteria2), скрининг и стресс-тестирование узлов через изолированный инстанс `sing-box`, дедупликация и бесшовная выгрузка лучших прокси в секции пакета **Podkop**.

---

## Ключевые возможности

* **Двухэтапный отбор узлов**:
* Быстрый скрининг пула (параллельные замеры задержки).


* Глубокий тест стабильности отобранных узлов (5 замеров, фильтрация по джиттеру и медиане).




* **Гибкое управление секциями Podkop**:
* Поддержка нескольких профилей/секций Podkop (`main`, `test`, кастомные).


* Глобальный или индивидуальный режим для каждого профиля: **Замена** (Replace) или **Добавление** (Append без дубликатов).




* **Лимит лучших узлов (Top-N)**:
* Возможность ограничить импорт серверов: **Все**, **Топ-3**, **Топ-5**, **Топ-10**.




* **Интеллектуальный фильтр RU**:
* Отсеивание российских узлов и узлов обхода блокировок внутри РФ.




* **Модульный Telegram-бот прямо на роутере**:
* **Управление подписками**: добавление по ссылке в чат с умным распознаванием, выбор и смена User-Agent (`v2rayN`, `FlClash`, `Sing-Box`, `Happ`, `Incy`), временное включение/отключение и удаление источников.


* **Управление парсером**: настройка порога пинга, лимитов серверов, режимов секций и запуск синхронизации в один клик.


* **Управление серверами**: посекционный просмотр узлов с пингами, ручной выбор активного сервера или сброс на автовыбор (URL-Test), точечное удаление мертвых нод.


* **Контроль сети**: мониторинг подключенных клиентов (Wi-Fi 2.4/5G, LAN) и аппаратная блокировка доступа по MAC/IP через `nftables`.


* **Диагностика**: экспресс-проверка доступности сервисов (YouTube, Discord, Steam и др.) и маршрутов произвольных URL (Fake-IP туннель или прямой провайдер).


* **Системная аналитика**: загрузка CPU/RAM, температура SoC, просмотр системных логов (`logread`, `dmesg`) и лога синхронизации.




* **Веб-интерфейс LuCI (4 вкладки)**:
* Удобное разделение: *Основные настройки*, *Секции Podkop*, *Telegram*, *Подписки*.


* Интерактивный дашборд узлов с переключателем секций, замером задержки и ручным сохранением выбранных серверов.




* **Умный планировщик cron**:
* Поддержка интервалов (1ч, 12ч, 24ч), запуска ежедневно в точное время (`ЧЧ:ММ`) или каждые N часов.




* **Автономный Watchdog**:
* Проверка доступности Podkop каждые 5 минут с динамическим определением LAN IP и автоматическим перезапуском/перепарсингом при сбое.

## Установка

Подключитесь к роутеру по SSH и выполните команду:

```sh
sh -c "$(curl -sL https://raw.githubusercontent.com/ib0lit/SubParser/main/install.sh)"

```

Скрипт автоматически определит пакетный менеджер (`opkg` или `apk`), установит зависимости (`python3`, `curl`, `conntrack`), развернет файлы сервиса, скомпилирует модули и зарегистрирует меню в LuCI.

После установки откройте веб-интерфейс: **LuCI → «Службы» → «SubParser»**.

---

## Обновление

Для обновления на актуальную версию без потери подписок, токенов бота и настроек:

```sh
sh -c "$(curl -sL https://raw.githubusercontent.com/ib0lit/SubParser/main/update.sh)"

```

Инсталлятор выполнит миграцию файловой структуры, очистит старый байткод и применит изменения в UCI.

---

## Удаление

Полное удаление сервиса с роутера:

```sh
sh -c "$(curl -sL https://raw.githubusercontent.com/ib0lit/SubParser/main/uninstall.sh)"

```

## Структура репозитория

```text
├── install.sh                              # Скрипт чистой установки
├── update.sh                               # Скрипт обновления с миграцией структуры
├── uninstall.sh                            # Полное удаление сервиса и библиотек
└── root/                                   # Файловая структура роутера
    ├── etc/
    │   ├── config/subparser                # Шаблон конфигурации UCI
    │   ├── hotplug.d/uci/99-subparser      # Хук на сохранение настроек в LuCI
    │   ├── init.d/subparser                # Служба управления задачами cron
    │   ├── init.d/subparser-bot            # procd-служба Telegram-бота
    │   └── subparser_version               # Версия пакета (2.1.0)
    ├── usr/
    │   ├── bin/subparser.py                # Ядро: тестирование, фильтрация и запись узлов
    │   ├── bin/subparser-bot.py            # Точка входа Telegram-бота
    │   ├── bin/subparser-helper.sh         # Мост команд между LuCI, RPC и бэкендом
    │   ├── bin/subparser-watchdog.sh       # Фоновый контроль доступности прокси
    │   ├── lib/subparser/                  # Модули логики бота
    │   │   ├── __init__.py
    │   │   ├── config.py                   # UCI, состояние и параметры
    │   │   ├── telegram.py                 # Обертка Telegram Bot API
    │   │   ├── subs.py                     # Управление и парсинг ссылок подписок
    │   │   ├── system.py                   # Мониторинг, nftables и клиенты сети
    │   │   ├── podkop.py                   # Взаимодействие с sing-box и узлами
    │   │   └── screens.py                  # Интерфейс и экраны меню бота
    │   └── share/
    │       ├── luci/menu.d/                # Регистрация меню LuCI
    │       └── rpcd/acl.d/                 # Права RPC для веб-интерфейса
    └── www/
        └── luci-static/resources/view/     # Фронтенд LuCI (subparser.js)

```
